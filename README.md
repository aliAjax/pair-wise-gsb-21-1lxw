# hxwl-07 维修放行检查工作台

维修部班前检查交接工具：按机型建立检查单，按 ATA 章节逐项记录，提交后由放行人员复核签发。

## 技术栈

React + Vite + TypeScript + CSS，数据保存在本机浏览器 localStorage。

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5107

## 功能

- **按机型建单**：选择机型、填写注册号创建检查单，覆盖 ATA 21/24/27/28/29/32/34/49 共 32 个检查项
- **逐项记录**：每项标记 正常 / 观察 / 缺陷；缺陷必须填写缺陷描述和处理意见
- **提交校验**：签署人未填、项目未查、缺陷缺描述或处理意见时无法提交，并列出全部缺项
- **自动保存**：填写过程实时写入本机浏览器，刷新或关机后内容不丢失
- **复核流转**：提交后内容锁定，放行人员可退回（必须写清原因，退回后可接着改）或签发放行
- **放行固定**：签发放行后检查单只读，不可再修改或删除
- **ATA 汇总**：工作台按 ATA 章节汇总完成量、缺陷项和待复核量，并展示检查单总览指标
- **角色切换**：页面右上角切换 维修工程师 / 放行人员 视角
