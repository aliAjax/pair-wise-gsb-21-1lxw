# hxwl-07 航空维修检查清单

按ATA章节推进维修放行前检查

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5107

## 功能

- 按机型（A320 / B737 / ARJ21 / C919）创建检查单，自动生成 ATA 章节检查项
- 逐项记录 正常 / 观察 / 缺陷；缺陷项必填缺陷描述与处理意见，观察项可填备注
- 提交校验：检查项未填完、缺陷缺描述或处理意见、缺少维修工程师签署时不能提交
- 填写内容实时自动保存到本机浏览器（localStorage），刷新不丢失
- 角色切换：维修工程师填写提交；放行人员复核，可退回（必填原因）或签发放行
- 退回后检查员可继续修改并重新提交；签发放行后内容锁定只读
- 按 ATA 章节汇总完成量、缺陷项、待复核量，顶部指标卡汇总整体进度
